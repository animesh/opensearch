## Pipeline overview

The pipeline is built using [Nextflow](https://www.nextflow.io/) and processes data using the following steps:

- [FragPipe](#fragpipe) - Primary open-search processing
- [Casanovo](#casanovo) - Optional de novo sequencing from calibrated mzML
- [AA_stat](#aa_stat) - Optional modification profiling from calibrated mzML and pepXML
- [Pipeline information](#pipeline-information) - Report metrics generated during workflow execution

### FragPipe

<details markdown="1">
<summary>Output files</summary>

- `fragpipe/`
  - `<sample>.FPv24hum/`: FragPipe work directory for each sample
  - `*_calibrated.mzML`: calibrated mzML files used by downstream tools
  - `*.pepXML`: peptide-spectrum match outputs used by AA_stat

</details>

FragPipe is executed in headless mode using user-provided workflow (`fp.dl.workflow.txt`) and manifest template (`fp.manifest.txt`) files.

### Casanovo

<details markdown="1">
<summary>Output files</summary>

- `casanovo/`
  - `<sample>.DNv5p1p2/`: Casanovo predictions per sample (when `--run_casanovo true`)

</details>

Casanovo runs on FragPipe-generated calibrated mzML files.

### AA_stat

<details markdown="1">
<summary>Output files</summary>

- `aa_stat/`
  - `<sample>.AA_stat_v2p5p6hum/`: AA_stat outputs per sample (when `--run_aa_stat true`)

</details>

AA_stat uses paired calibrated mzML and pepXML outputs from FragPipe.

### Pipeline information

<details markdown="1">
<summary>Output files</summary>

[Nextflow](https://docs.seqera.io/platform-cloud/reports/overview) provides excellent functionality for generating various reports relevant to the running and execution of the pipeline. This will allow you to troubleshoot errors with the running of the pipeline, and also provide you with other information such as launch commands, run times and resource usage.

## Integrated OpenSearch report

The pipeline adds an integrated MultiQC layer when FragPipe, Casanovo and AA_stat are all run. The new sections are generated by `bin/opensearch_summary.py` and use MultiQC custom-content files.

The integrated report contains:

- Executive summary of PSMs, peptides, proteins, Casanovo sequencing and AA_stat mass shifts.
- General statistics including de novo/PSM ratio and Casanovo/FragPipe exact sequence overlap.
- Identification funnel comparing Casanovo sequences with FragPipe PSMs, peptides and proteins.
- Casanovo confidence thresholds read directly from the Casanovo log.
- Exact sequence overlap between unique Casanovo sequences and FragPipe peptide sequences after removing Casanovo modification annotations.
- AA_stat mass-shift landscape excluding isotope shifts, with the highest reported AA_stat interpretation match shown as annotation.
- Automatically generated descriptive QC observations.

Casanovo-only sequences are deliberately described as candidates rather than novel peptides. Exact sequence non-overlap is not proof of novelty because modifications, de novo errors, search-space differences and other effects can produce non-overlap.
